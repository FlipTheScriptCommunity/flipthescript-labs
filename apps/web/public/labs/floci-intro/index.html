ענן על המחשב שלך

להתחיל עם Floci בעשר דקות — בלי חשבון AWS, בלי כרטיס אשראי, בלי לשלם שקל.

חינם לגמרי עובד בלי אינטרנט אי אפשר לשבור כלום

רגע, מה זה בכלל?

“ענן” זה בסך הכל מחשבים של מישהו אחר, רחוק. Floci מריץ העתק קטן שלהם — אצלך.

הרעיון היחיד שצריך להבין

לכל פקודה שאתה שולח לענן יש כתובת. משנים את הכתובת — והפקודה מגיעה למחשב שלך במקום לאמזון. הפקודה עצמה לא משתנה בכלל.

התחלה מהירה (דקה אחת)

צריך רק Docker. כל השאר הוא אוטומטי.

1

מתקינים Docker

מורידים מ־docker.com, מתקינים, פותחים.

אם כבר יש Docker, דלגו לשלב 2.
2

בפקודה אחת

Clone את ה-repo, נכנסו לתוכו, והריצו את הסקריפט הזה:

# Mac / Linux
./setup-floci.sh
# Windows
setup-floci.bat
הסקריפט מעלה את Floci, מוריד את התוכנה בפעם הראשונה, וקובע את כל ה-env vars. זה הכל.
3

טסטו

Bucket זו תיקייה בענן. בדקו שהכל עובד:

set -a; source .env.floci; set +a  # Mac/Linux
aws s3 mb s3://my-test-bucket
aws s3 ls
רואים את השם ברשימה? מוכנים! 🎉

שלבים ידניים (אם אתם רוצים להבין כל דבר)

כך קורה בצד הקלעים כשאתם מריצים את הסקריפט. שימוש — אם אתם אוהבים בניית דברים ידני או למידה עמוקה.

1

מתקינים Docker

Docker זו תוכנה שיודעת להריץ תוכנות אחרות בתוך “קופסה” מבודדת. Floci רץ בקופסה כזו. מורידים מ־docker.com, מתקינים, פותחים.

בדקו שהוא עובד: docker --version
2

מרימים את Floci

פקודה אחת. בפעם הראשונה זה מוריד את התוכנה, אחר כך זה מיידי. 

docker run -d --name floci -p 4566:4566 floci/floci
-p 4566:4566 אומר: “פתח את דלת מספר 4566”. זו הכתובת מהאיור למעלה. (או השתמשו ב-docker-compose.yml שבפוקט.)
3

מפנים את הכתובת

אומרים ל-AWS CLI לשלוח הכל למחשב שלך. הסיסמאות מזויפות — Floci לא בודק אותן. 

# Mac / Linux
export AWS_ENDPOINT_URL=http://localhost:4566
export AWS_ACCESS_KEY_ID=test
export AWS_SECRET_ACCESS_KEY=test
export AWS_DEFAULT_REGION=us-east-1
# Windows PowerShell
$env:AWS_ENDPOINT_URL="http://localhost:4566"
$env:AWS_ACCESS_KEY_ID="test"
$env:AWS_SECRET_ACCESS_KEY="test"
$env:AWS_DEFAULT_REGION="us-east-1"
או: set -a; source .env.floci; set +a (אחרי שעתקתם את .env.floci.example)
4

יוצרים משהו

Bucket זו תיקייה בענן. הפקודה הזו יוצרת אחת — בדיוק אותה פקודה שהיית מריץ מול AWS אמיתי. 

aws s3 mb s3://my-first-bucket
aws s3 ls
רואה את השם ברשימה? יש לך ענן עובד על המחשב. 🎉

שאלות שכולם שואלים

זה באמת בחינם? כן. קוד פתוח ברישיון MIT, בלי הרשמה ובלי טוקן. הכל רץ אצלך.
אני יכול לשבור משהו? לא. אין קשר לחשבון AWS אמיתי. הכי גרוע — מוחקים את הקונטיינר ומתחילים מחדש.
איפה הדברים שיצרתי? בזיכרון. מכבים את הקונטיינר — הכל נעלם. זו תכונה, לא באג: כל הרצה מתחילה נקי.
איך עוצרים? docker stop floci ואם רוצים גם למחוק — docker rm floci.
מה ההבדל מ-LocalStack? LocalStack התחילה לדרוש טוקן ב-2026. Floci עושה את אותו דבר בלי הרשמה, ומתחיל ב-24 אלפיות שנייה.
