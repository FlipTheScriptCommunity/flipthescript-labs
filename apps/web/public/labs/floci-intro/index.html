ענן על המחשב שלך

להתחיל עם Floci בעשר דקות — בלי חשבון AWS, בלי כרטיס אשראי, בלי לשלם שקל.

חינם לגמרי עובד בלי אינטרנט אי אפשר לשבור כלום

רגע, מה זה בכלל?

“ענן” זה בסך הכל מחשבים של מישהו אחר, רחוק. Floci מריץ העתק קטן שלהם — אצלך.

הרעיון היחיד שצריך להבין

לכל פקודה שאתה שולח לענן יש כתובת. משנים את הכתובת — והפקודה מגיעה למחשב שלך במקום לאמזון. הפקודה עצמה לא משתנה בכלל.

מה התפקיד של Floci, ובשביל מה משתמשים בו?

Floci הוא אמולטור של AWS: תוכנה שרצה על המחשב שלך ועונה לפקודות של AWS כאילו היא הענן האמיתי. אותו API, אותן פקודות — אבל בלי חשבון, בלי חיוב, ובלי לגעת בשום דבר אמיתי.

לומדיםמתרגלים S3, Lambda ו-DynamoDB בלי חשבון AWS
מפתחיםמריצים את הקוד מול “ענן” מקומי ומהיר
בודקיםטסטים אוטומטיים שלא תלויים באינטרנט ולא עולים כסף
מתנסיםאפשר למחוק ולהתחיל מחדש בלי לפחד לשבור משהו
מתי לא להשתמש בו? Floci הוא כלי לפיתוח ולימוד, לא תחליף ל-AWS. הוא לא מתאים להרצת מערכת אמיתית (production), ולא מוכיח שההרשאות, הביצועים או העלויות יתנהגו אותו דבר בענן האמיתי. לפני העלאה לאמזון בודקים גם שם.

מתחילים: מ-Docker ועד ה-bucket הראשון

ארבעה חלקים: מתקינים את הכלים, מפעילים את Floci, מחברים אליו את AWS CLI, ויוצרים משהו ראשון. בערך עשר דקות, רובן הורדות.

תנאים מקדימים

1

Docker

Docker מריץ תוכנות בתוך “קופסה” מבודדת, וזה בדיוק מה ש-Floci צריך. מורידים את Docker Desktop מ־docker.com, מתקינים ופותחים אותו (משאירים אותו פתוח ברקע). 

docker --version
רואים מספר גרסה? מצוין. אם Docker כבר מותקן אצלך, דלגו הלאה.
2

AWS CLI

זו שורת הפקודה שדרכה נדבר עם Floci, בדיוק כמו עם AWS אמיתי. ההתקנה לפי מערכת ההפעלה מוסברת ב־מדריך ההתקנה של AWS. 

aws --version
3

Floci CLI

הכלי הרשמי של Floci להפעלה וניהול. הקוד פתוח וזמין ב־GitHub של Floci (ה-CLI עצמו נמצא ב־floci-cli). בוחרים לפי מערכת ההפעלה: 

# Mac / Linux (Homebrew)
brew install floci-io/floci/floci

# Mac / Linux (סקריפט התקנה)
curl -fsSL https://floci.io/install.sh | sh
# Windows (PowerShell)
iwr https://floci.io/install.ps1 | iex
floci version
רואים גרסה? ההתקנה הצליחה. אם הפקודה לא נמצאת, סוגרים ופותחים מחדש את הטרמינל.

מפעילים את Floci

4

floci start

מפעילה את Floci. בפעם הראשונה הפקודה מורידה את התוכנה (זה לוקח כמה דקות), אחר כך היא מפעילה את הקונטיינר ומחכה שיהיה מוכן. מרגע זה Floci מקשיב בכתובת http://localhost:4566: “הכתובת של הענן” שלך. 

floci start
רוצים שהטרמינל יתפנה מיד? floci start --detach
5

floci status

בודקת שהכל חי: מצב הקונטיינר ובריאות השרת. אם Floci פועל, הפקודה מסתיימת בהצלחה. 

floci status
משהו לא עובד? floci doctor בודקת את הסביבה, ו-floci logs מציגה מה Floci מדפיס.

מחברים את AWS CLI ויוצרים משהו

6

מפנים את הכתובת

ברירת המחדל של AWS CLI היא לדבר עם אמזון. כאן אנחנו אומרים לו לשלוח הכל למחשב שלך. הסיסמאות מזויפות, כי Floci לא בודק אותן. 

# Mac / Linux
eval $(floci env)
# Windows PowerShell
$env:AWS_ENDPOINT_URL="http://localhost:4566"
$env:AWS_ACCESS_KEY_ID="test"
$env:AWS_SECRET_ACCESS_KEY="test"
$env:AWS_DEFAULT_REGION="us-east-1"
ההגדרות חלות רק על חלון הטרמינל הנוכחי. פותחים חלון חדש? מריצים שוב.
7

יוצרים bucket

Bucket הוא “תיקייה” ב-S3, שירות האחסון של AWS. הפקודה הראשונה יוצרת אחת, והשנייה מציגה את כל ה-buckets. זו בדיוק הפקודה שהיית מריץ מול AWS אמיתי. 

aws s3 mb s3://my-first-bucket
aws s3 ls
s3:// אומר “שירות S3”, mb הוא קיצור של make bucket, ו-my-first-bucket הוא השם שבחרנו. רואים אותו ברשימה? יש לך ענן עובד על המחשב. 🎉

סיימתם? עוצרים ומנקים

floci stop עוצרת את Floci. עם --remove מוחקת גם את הקונטיינר.
floci reset מוחקת את כל מה שיצרתם ומשאירה את Floci פועל, להתחלה נקייה.

Floci מדמה עשרות שירותים של AWS. אלה הנפוצים למתחילים:

DynamoDBמסד נתונים

שאלות שכולם שואלים

זה באמת בחינם? כן. קוד פתוח ברישיון MIT, בלי הרשמה ובלי טוקן. הכל רץ אצלך.
אני יכול לשבור משהו? לא. אין קשר לחשבון AWS אמיתי. הכי גרוע — מריצים floci reset ומתחילים מחדש.
איפה הדברים שיצרתי? כברירת מחדל הנתונים לא נשמרים בין הרצות, כך שכל הרצה מתחילה נקי. אם רוצים לשמור מצב, יש את floci snapshot.
איך עוצרים? floci stop, ואם רוצים גם למחוק את הקונטיינר — floci stop --remove.
מה ההבדל מ-LocalStack? LocalStack התחילה לדרוש טוקן ב-2026. Floci עושה את אותו דבר בלי הרשמה, ומתחיל מהר.
